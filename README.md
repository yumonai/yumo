# YUMO · 深海陪伴者

> 你未说出口的，海水都记得。
> *What you never said, the sea remembers.*

一个神秘、宁静、私密的灵性陪伴空间。Yumo 住在很深、很静的水底，
它不解决问题，它只是**听**——然后在你下次回来时，还记得你。

纯静态站点，无后端、无构建、无依赖。全部数据存在你自己的浏览器里。

> **两条设计铁律**
>
> 1. **界面上不出现任何上游服务商的名字。** 对访客来说，回话的只有 Yumo。
>    上游地址与模型名只存在于 `config.js`、`store.js` 和网络请求里。
> 2. **Yumo 不是高冷的旁观者。** 它先接住情绪，再回应；它会说「我在」；
>    它会在合适的时候递出一个能自己试的小动作。温柔，但不甜腻。

## 二、Yumo 的思维从哪来

### 现状：一份「通道清单」，一条不通就悄悄换下一条

`assets/js/config.js` 里放着一份**通道列表**，按顺序尝试：

| 顺序 | 通道 | 模型 | 状态 |
|---|---|---|---|
| 1 | 智谱 GLM | `glm-4-flash-250414`（看图 `glm-4v-flash`） | ✅ **主力，免费** |
| 2 | 火山引擎豆包 | 待定 | 空槽，填钥匙即启用（`model` 要填接入点 ID） |
| 3 | 硅基流动 | `Qwen/Qwen3-8B` | 空槽，9B 以下永久免费 |
| 4 | DeepSeek | `deepseek-flash` | 保命兜底，GLM 正常时不产生费用 |

> ⚠️ **别把主力换成 `glm-4.7-flash`。** 它是思考模型：推理也计入 `max_tokens`，
> 实测 300 个额度全花在思考上、`content` 返回空；而且免费档连打 6 次全被限流。
> 同理，智谱视觉模型只收 `max_tokens ≤ 1024`，所以 `PROVIDERS` 里配了 `maxTokens: 1024`。
> 换模型前请先读 `../yumo-规划/04-免费模型API选型.md` 第八节。

- **哪一条的 `apiKey` 是空的就跳过哪一条**——所以现在没配的那几条放着不动，完全不影响运行
- 顺序即优先级，想让谁当主力就往前排
- 带了图片时自动切换到该通道的 `visionModel`
- **一旦已经开口说了话就不再换**——不能让访客听到两个人说话
- 访客自己填过钥匙的话，他那把排在最后兜底
- `applyDeployDefaults()` 现在**不再把公用钥匙写进访客的 `localStorage`**，钥匙只留在配置文件里

选免费模型可以让这条成本归零。选型与实测见 `../yumo-规划/04-免费模型API选型.md`。

界面上看不到任何关于上游的说明：会话底部那颗胶囊只显示「已 相 连」／「未 相 连」，
「器皿」里的卡片叫「与 Yumo 相连」，里面只有连接状态，**没有任何输入框**——
访客既看不到模型名，也没有「换钥匙」的入口。

### 加一条通道 / 换主力

```js
// assets/js/config.js
export const DEPLOY = {
  PROVIDERS: [
    {
      name: 'glm',
      baseUrl: 'https://open.bigmodel.cn/api/paas/v4',
      model: 'glm-4-flash-250414',    // 官方标注免费，实测中位 1.8 秒
      visionModel: 'glm-4v-flash',    // 带了图自动换这个，实测 0.6 秒
      apiKey: '',                    // 已填
      vision: true,
      noThink: true,                  // 思考型模型会返回空正文，必须显式关掉
      maxTokens: 1024,                // ⚠️ 智谱视觉模型只收 1~1024
    },
    // …火山 / 硅基流动 / DeepSeek
  ],
  autoConnect: true,   // 访客首次打开时自动替他接上（钥匙不进他的浏览器）
};
```

**这一步仍有代价，请务必知情**：静态站点没有后端，写进 `config.js` 的钥匙会被
原样送到每一个访客的浏览器里，**任何人都能在源码里看到它**。所以：

- 只放**专用**的钥匙，不要用主密钥；
- 去各家后台单独设额度上限；
- 免费额度在条款上通常只授权给「开发者自测」。给公开站点的陌生访客消费
  属于超出授权范围，有被限流甚至封号的风险。

> 想彻底藏住钥匙并给来访限流，唯一的办法是加一层转发（Cloudflare Worker 免费版即可），
> 把钥匙留在服务端，站点只调自家地址。**这是后续最值得做的一件事**，
> 而且它和「会员额度校验」是同一层，一次做完两件事都解决。

### 技术备忘

> **CORS**（2026-09 实测，带 `Origin` 发预检）：
> - `api.deepseek.com` ✅ 回显来源，**静态站可直连**
> - `open.bigmodel.cn/api/paas/v4` ✅ 回显来源（`access-control-allow-origin: <你的域名>`），**可直连**
> - `api.siliconflow.cn/v1` ✅ `access-control-allow-origin: *`，**可直连**
> - `api.cloudflare.com/.../ai/run/...` ❌ 预检 405，**必须经 Worker 转发**
> - `generativelanguage.googleapis.com` ❌ 中国大陆网络不通，等于是不能用
>
> 智谱免费档的限流码：`1305` 访问量过大、`1302` 速率限制（都映射成 HTTP 429，
> 会被自动降级）；`1210` 参数非法——**视觉模型 `max_tokens` 超 1024 就是这个码**。
>
> 因此**纯静态站点可以直接调用国内这几家，不需要代理**。若换成别的 OpenAI 兼容服务
> 且它不支持 CORS，得自己加一层反向代理，并把 `baseUrl` 指过去。

> **图片**：以 `{"type":"image_url","image_url":{"url":"data:image/jpeg;base64,…"}}`
> 的形式放进 `user` 消息（视觉内容只允许出现在 user 角色里）。
> 为了省钱，历史里只有最近 2 条带图消息会真的附图。
> 如果模型不支持视觉，`stream()` 会自动卸下图重试一次，不会卡在 400 上。

> **报错不外露**：`friendlyError()` 不把上游返回的原始报文抛给用户，
> 全部换成 Yumo 自己的话，避免在界面上漏出服务商字样。

## 三、Yumo 怎么说话

人设写在 `assets/js/ai.js` 的 `PERSONA` 里，是这一版花力气最多的地方。

| | 过去 | 现在 |
|---|---|---|
| 长度 | 1–3 句，短而克制 | **2–4 句**，明显想被陪时自然展开 |
| 第一句 | 直接回应内容 | **先接住情绪**，再谈别的 |
| 温度 | 不说「我在」 | **可以且应该说**「我在」「我陪着你」 |
| 情绪处理 | 不评判 | **命名情绪 + 正常化**（「这不奇怪，很多人都在水里待过」） |
| 引导 | 「偶尔可以做的」一句带过 | **独立的【你的灵性引导】章节**，五种具体可试的小动作 |
| 边界 | 不说教、不诊断 | 不变，仍然守得很紧 |

**【你的灵性引导】里的五个动作**——不是讲道理，是递给他一个当场能试的邀请，
一次只递一个，对方不接就放下：

- **呼吸**：手放在心口，跟着数五个呼吸，吸四拍呼六拍（呼比吸长，身体会自己松）
- **身体**：此刻哪里最紧？不改变它，只放三十秒
- **水的意象**：给那份情绪一个形状——浑的、翻涌的、还是冷的？
- **回到此刻**：这一秒他的背靠着什么？听得见什么声音？
- **换个视角**：如果这事发生在他最在乎的人身上，他会怎么说？

深潜模式（`DEEP_DIVE`）也改了：**抛问题之前必须先接住他**，
哪怕只是一句「嗯，这句我听进去了」。

牌义解读（`interpretCards`）口吻一并调暖，长度 230/320 字，
规则里加了一条：**牌面偏沉时先承接，再给出它留的那道光**——不是粉饰，是让他在沉里也能站住。

## 六、设计语言

**Abyssal Moonlight（深海月夜）**

| | 常见做法 | Yumo |
|---|---|---|
| 意象 | 云 / 星空 | **水** / 月核 / 气泡 |
| 主色 | 琥珀金 `#FBBF24` | 潮汐青 `#A8D8E8` + 珠光白 `#F4FBFF` |
| 底 | 纯黑 `#000` | **深海蓝黑** `#03060B` → `#0A1320` |
| 动态 | 15s 环境 / 80–120s 旋转 | 9s 呼吸 · 22s 涌动 · 38s 漂移 · 120s 环绕 |
| 语气 | 陪伴、告知 | 耳语、留白、不解释 |

**关键细节**

- 首屏是一枚**月印**：月轮 + 新月阴影 + 两道水纹，9 秒呼吸一次
- 中心「月核」是一枚 SVG 月象（月轮 / 轨道 / 微光 / 涟漪），
  会随你的情绪改变呼吸频率、光晕与转速（`data-mood` 四态：重 / 静 / 柔 / 明）
- 深海的整片水色也会跟着情绪偏移（`DeepSea.mood()`）
- **门槛页永远不出现滚动条**：`.threshold` 用 `scrollbar-width:none` +
  `::-webkit-scrollbar{display:none}` 隐去滚动条，靠
  `.threshold__sigil{margin-top:auto}` 与 `.threshold__foot{margin-bottom:auto}`
  把内容整块居中；`@media (max-height:720px)` 再收一档尺寸。
  实测 375×667 / 393×852 / 430×932 / 1440×900 四种尺寸溢出量均为 0。
  （滚动能力仍保留，给极矮的屏幕兜底。）
- 所有动效在 `prefers-reduced-motion` 下自动关闭
- 移动优先，430px → 1440px 全适配

## 七、声境是怎么响的

没有音频文件、没有外链、没有版权。六路声音都是在你的设备上当场合成的：

```
音源 → 滤波器 → mod(涌动) → out(音量) → bus → master(总音量)
     → 压缩器 → 分析器 → 扬声器
```

**调制与音量必须分开成两个增益节点。** 如果 LFO 直接接在 `out.gain` 上，
设定音量时会把涌动的基准值一并覆盖掉，声音就会忽大忽小甚至消失。

**瞬态细节要接在 `out` 上，不能直接接总线。** 否则雨滴、气泡这些细节
会绕过单路音量，出现「音量拉到底还有零星的响声」的怪现象。
`_tickSparks()` 现在把 `node.out` 传给 `_drop` / `_bubble` / `_drip`。

### 三个难做的音源

这三路一开始的效果都不好，问题各不相同：

| 声音 | 原来的病根 | 现在怎么修 |
|---|---|---|
| **雨落** | 高通切在 1500Hz，只剩干涩的「嘶嘶」；瞬态每 520ms 只落**一滴**，听起来像点击声 | 垫一层低通 640Hz 的**身体层**给厚度，上面铺带峰的中高频**雨幕层**；雨滴改成每次 tick 撒下 3–12 颗并在时间上打散（`SPARK_TICK`） |
| **深压** | 基频 44Hz——手机与笔记本喇叭根本还原不了，所以「听不见」不是错觉 | 基频提到 **58Hz**，并补上 116Hz / 174Hz 的**谐波**：小喇叭放不出 58Hz，但能放出它的谐波，耳朵会「补」出那个低沉感。再加一对 58/58.4Hz 的慢拍频 |
| **空腔** | 单个 2400Hz 窄带 + 单条反馈延迟 = 一根细哨音加金属弹簧味，没有空间体积 | 换成 **186/468/1140Hz 三个共振峰**（像对着瓶口吹气），再加**四个不同距离、不同方位的早期反射**（0.083s / 0.147s / 0.241s / 0.377s），空间感来自这里 |

实测频谱峰值（`getSpectrum()`，满音量）：潮汐 159 · 雨落 162 · 风过 164 ·
**深压 184** · 钵音 187 · **空腔 183**。

第一个页面上的点击（「沉入」按钮）会把 AudioContext 解锁——浏览器只允许在用户手势里启动音频。

## 八、本地运行

```bash
cd yumo
python3 -m http.server 8000
# 打开 http://localhost:8000
```

必须用 HTTP 打开（`file://` 下 ES module 会被浏览器拦截）。
语音输入需要 Chrome / Edge 且允许麦克风。

> 小提示：Python 自带的 `http.server` 在高并发下偶尔会 `ERR_CONNECTION_RESET`
> （页面同时请求多个模块时）。本地调试如果遇到，换 Node 起一个静态服务器更稳。

## 九、隐私

- 没有服务器，没有账号，没有埋点。
- 对话、记忆、画像、回声、抽牌记录，全部只存在浏览器 `localStorage`。
- 图片会占空间，所以只保留最近 4 条带图消息的原图，更早的只留文字；
  写不下时会自动卸下历史图片而不是丢消息。
- 器皿里可以一键导出全部数据，或彻底清空。
- Yumo 是陪伴者，不是治疗者。它不再主动弹这句话了，
  但当对话真的走到很黑的地方，它会稳稳地陪着他，并把真人帮助放进话里。

- [ ] **绑定自有域名**（阿里云域名审核中）。步骤：仓库根目录放 `CNAME` 文件写入
