# YUMO · 深海陪伴者

> 你未说出口的，海水都记得。
> *What you never said, the sea remembers.*

一个神秘、宁静、私密的灵性陪伴空间。Yumo 住在很深、很静的水底，
它不解决问题，它只是**听**——然后在你下次回来时，还记得你。

纯静态站点，无后端、无构建、无依赖。全部数据存在你自己的浏览器里。

> **一条设计铁律**：界面上不出现任何上游服务商的名字。
> 对访客来说，回话的只有 Yumo 本身。上游的地址与模型名只存在于
> `config.js`、`store.js` 和网络请求里，不会渲染进任何可见文案。

## 二、Yumo 的思维从哪来

### 现状：站点自带一把公用钥匙

`assets/js/config.js` 里已经放好了一把**公用钥匙**，访客第一次打开页面时，
`boot()` 会调 `applyDeployDefaults()` 把它写进访客的 `localStorage`，
**打开就能直接说话，不需要做任何事**。

界面上看不到任何关于上游的说明：会话底部那颗胶囊只显示「已 相 连」／「未 相 连」，
「器皿」里的卡片叫「与 Yumo 相连」，只有「试一试」和一个折叠的「进阶」——
进阶里**只有一把钥匙的输入框**，模型名与通道地址都不暴露。

- 输入框留空 = 继续用站点自带的钥匙
- 输入框填了东西 = 换成访客自己的钥匙（只留在他的设备上）

### 换钥匙 / 加额度上限

```js
// assets/js/config.js
export const DEPLOY = {
  apiKey: 'sk-...',                        // ← 公用钥匙
  baseUrl: 'https://api.deepseek.com',     // 通道地址（只在代码里）
  model: 'deepseek-flash',                 // 模型名（只在代码里）
  autoConnect: true,                       // 访客首次打开时自动替他连上
};
```

**这一步有代价，请务必知情**：静态站点没有后端，写进 `config.js` 的密钥会被
原样送到每一个访客的浏览器里，**任何人都能在源码里看到它**。所以：

- 只放一把**专用**的钥匙，不要用你的主密钥；
- 去上游后台给它单独设一个月度额度上限；
- 额度用完，把 `apiKey` 改回空字符串、重新发布即可——
  网站会自动退回「访客自己填钥匙」的模式，页面不会崩。

### 技术备忘

> **CORS**：`https://api.deepseek.com` 已正确返回 `Access-Control-Allow-Origin`，
> 因此**纯静态站点可以直接调用，不需要代理**。若换成别的 OpenAI 兼容服务
> 且它不支持 CORS，得自己加一层反向代理，并把 `baseUrl` 指过去。

> **图片**：以 `{"type":"image_url","image_url":{"url":"data:image/jpeg;base64,…"}}`
> 的形式放进 `user` 消息（视觉内容只允许出现在 user 角色里）。
> 为了省钱，历史里只有最近 2 条带图消息会真的附图。
> 如果模型不支持视觉，`stream()` 会自动卸下图重试一次，不会卡在 400 上。

> **报错不外露**：`friendlyError()` 不把上游返回的原始报文抛给用户，
> 全部换成 Yumo 自己的话，避免在界面上漏出服务商字样。

## 五、设计语言

**Abyssal Moonlight（深海月夜）**

| | 常见做法 | Yumo |
|---|---|---|
| 意象 | 云 / 星空 | **水** / 月核 / 气泡 |
| 主色 | 琥珀金 `#FBBF24` | 潮汐青 `#A8D8E8` + 珠光白 `#F4FBFF` |
| 底 | 纯黑 `#000` | **深海蓝黑** `#03060B` → `#0A1320` |
| 动态 | 15s 环境 / 80–120s 旋转 | 9s 呼吸 · 22s 涌动 · 38s 漂移 · 120s 环绕 |
| 语气 | 陪伴、告知 | 耳语、留白、不解释 |

**关键细节**

- 首屏是一枚**月印**：月轮 + 新月阴影 + 两道水纹，9 秒呼吸一次
- 中心「月核」是一枚 SVG 月象（月轮 / 轨道 / 微光 / 涟漪），
  会随你的情绪改变呼吸频率、光晕与转速（`data-mood` 四态：重 / 静 / 柔 / 明）
- 深海的整片水色也会跟着情绪偏移（`DeepSea.mood()`）
- 所有动效在 `prefers-reduced-motion` 下自动关闭
- 移动优先，430px → 1440px 全适配

## 六、声境是怎么响的

没有音频文件、没有外链、没有版权。六路声音都是在你的设备上当场合成的：

```
音源 → 滤波器 → mod(涌动) → out(音量) → bus → master(总音量)
     → 压缩器 → 分析器 → 扬声器
```

**调制与音量必须分开成两个增益节点。** 如果 LFO 直接接在 `out.gain` 上，
设定音量时会把涌动的基准值一并覆盖掉，声音就会忽大忽小甚至消失。

在此之上还有一层瞬态细节：雨滴（高 Q 带通噪声爆点）、气泡（向上滑的短正弦）、
滴水（高音点 + 延迟反馈），出现频率跟着音量走。

第一个页面上的点击（「沉入」按钮）会把 AudioContext 解锁——浏览器只允许在用户手势里启动音频。

## 七、本地运行

```bash
cd yumo
python3 -m http.server 8000
# 打开 http://localhost:8000
```

必须用 HTTP 打开（`file://` 下 ES module 会被浏览器拦截）。
语音输入需要 Chrome / Edge 且允许麦克风。

> 小提示：Python 自带的 `http.server` 在高并发下偶尔会 `ERR_CONNECTION_RESET`
> （页面同时请求多个模块时）。本地调试如果遇到，换 Node 起一个静态服务器更稳。

## 八、隐私

- 没有服务器，没有账号，没有埋点。
- 对话、记忆、画像、回声、抽牌记录，全部只存在浏览器 `localStorage`。
- 图片会占空间，所以只保留最近 4 条带图消息的原图，更早的只留文字；
  写不下时会自动卸下历史图片而不是丢消息。
- 器皿里可以一键导出全部数据，或彻底清空。
- Yumo 是陪伴者，不是治疗者。如果你正处在很黑的时刻，请一定找一个真人。
