# YUMO · 深海陪伴者

> 你未说出口的，海水都记得。
> *What you never said, the sea remembers.*

一个神秘、宁静、私密的灵性陪伴空间。Yumo 住在很深、很静的水底，
它不解决问题，它只是**听**——然后在你下次回来时，还记得你。

纯静态站点，无后端、无构建、无依赖。全部数据存在你自己的浏览器里。

## 二、接入 DeepSeek

1. 打开站点 → 底栏 **器皿**（或首屏「设置」）
2. 填入 DeepSeek 的 API Key（`sk-...`）
3. 模型默认 `deepseek-chat`，可按需改成你实际使用的版本名
4. 点「试一试」确认连通

密钥只写入本机 `localStorage`，不上传任何地方。

> **关于 CORS**：DeepSeek 官方 API（`https://api.deepseek.com`）已正确返回
> `Access-Control-Allow-Origin`，因此**纯静态站点可以直接调用，不需要代理**。
> 如果你换成别的 OpenAI 兼容服务且它不支持 CORS，请把「接口地址」指向
> 你自己的反向代理。

> **关于图片**：DeepSeek 的对话模型目前不接受视觉输入。附上的图片会完整保存在
> 本地消息记录与花园里，但 Yumo 只能读到文字。要让它"看见"，需要把
> `assets/js/ai.js` 里的 `stream()` 换成多模态端点。

## 四、设计语言

**Abyssal Moonlight（深海月夜）** —— 与同类产品刻意的区分：

| | 常见做法 | Yumo |
|---|---|---|
| 意象 | 云 / 星空 | **水** / 月核 / 气泡 |
| 主色 | 琥珀金 `#FBBF24` | 潮汐青 `#A8D8E8` + 珠光白 `#F4FBFF` |
| 底 | 纯黑 `#000` | **深海蓝黑** `#03060B` → `#0A1320` |
| 动态 | 15s 环境 / 80–120s 旋转 | 9s 呼吸 · 22s 涌动 · 38s 漂移 · 120s 环绕 |
| 语气 | 陪伴、告知 | 耳语、留白、不解释 |

**关键细节**

- 中心「月核」会随你的情绪改变呼吸频率与光晕（`data-mood` 四态：重/静/柔/明）
- 深海的整片水色也会跟着情绪偏移（`DeepSea.mood()`）
- 所有动效在 `prefers-reduced-motion` 下自动关闭
- 移动优先，430px → 1440px 全适配

## 五、本地运行

```bash
cd yumo
python3 -m http.server 8000
# 打开 http://localhost:8000
```

必须用 HTTP 打开（`file://` 下 ES module 会被浏览器拦截）。
语音输入需要 Chrome / Edge 且允许麦克风。

## 六、隐私

- 没有服务器，没有账号，没有埋点。
- 对话、记忆、画像、回声、抽牌记录，全部只存在浏览器 `localStorage`。
- 器皿里可以一键导出全部数据，或彻底清空。
- Yumo 是陪伴者，不是治疗者。如果你正处在很黑的时刻，请一定找一个真人。
